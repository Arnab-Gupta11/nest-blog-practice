# Project Guidelines & Rules

1. **Implementation Plan First**:
   - Before making any code changes, always provide a detailed implementation plan (`implementation_plan.md` or detailed breakdown).
   - Specify exactly what will be changed and in which files.
   - Wait for explicit user review and approval (or user-requested modifications) before editing any codebase files.

2. **Follow Existing File Structure**:
   - Strictly follow the project's existing directory structure, modular setup, and naming conventions when creating or modifying code.
